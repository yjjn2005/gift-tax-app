# 유앤김 패밀리 증여 레지스트리

증여·대여 이력 관리 · 증여세 자동계산 · **증여세 0원 역산**을 하나로 묶은 개인용 웹앱입니다.

- 배포(정식): https://gift-tax-app.yjjn2005.workers.dev
- 원본 데이터: `유앤김_패밀리_증여이력_관리럭셔리에디션.xlsx` (2026.08.04 기준)

## 기능

| 탭 | 내용 |
|---|---|
| 대시보드 | 총 증여/세금/대여, 수증자별 카드, 직계존속 공제 잔여 게이지 |
| 인별 이력 | 수증자별 증여·대여 이력 CRUD, 소계, 관계그룹별 공제 잔여 한도 |
| 증여세 계산 | 날짜+금액 입력 시 실시간 자동계산, 11단계 산출내역 상세 표시 |
| 0원 역산 | ① 날짜 → 무세 최대금액 ② 금액 → 무세가 되는 가장 빠른 년·월·일 |
| 무세 캘린더 | 공제 한도가 되살아나는 분기점별 무세 증여 가능액 시간표 |
| 설정·동기화 | 가족 관계 설정, 6자리 코드 기반 전 기기 동기화, 백업/복원, CSV |

## 세액엔진

상속세및증여세법 기준으로 아래를 모두 반영합니다.

1. **10년 합산** — 증여일 전 10년 내 동일인(직계존속은 그 배우자 포함) 증여 합계가 1천만원 이상이면 가산
2. **증여재산공제** — 배우자 6억 / 직계존속 5천만(미성년 2천만) / 직계비속 5천만 / 기타친족 1천만, 관계그룹별 10년 한도를 날짜순으로 배분
3. **혼인·출산 증여재산공제** — 2024.1.1~ 직계존속 증여분, 통합 평생 1억 (일반공제와 별도)
4. **세율** — 1억 10% / 5억 20%(누진공제 1천만) / 10억 30%(6천만) / 30억 40%(1.6억) / 초과 50%(4.6억)
5. **세대생략 할증** — 산출세액의 30% (미성년 + 20억 초과 시 40%)
6. **기납부세액공제** — 종전 증여분 산출세액 상당액, 한도 적용
7. **신고세액공제** — 2016년 이전 10% / 2017년 7% / 2018년 5% / 2019년~ 3%
8. 과세표준 50만원 미만 부과 제외 · 납부세액 10원 미만 절사

### 검증

엑셀의 실제 신고세액 26건과 대조하여 **21건이 원 단위까지 일치**합니다.
불일치 5건의 원인은 모두 확인되었습니다 (README 하단 `검증` 절 참고).

```
유창노→유재진 2017.05.25  445,811,775원 → 64,320,990원  (신고액과 일치)
유창노→유해인 2017.05.25  267,487,065원 → 40,498,370원  (세대생략 30% 할증 포함, 일치)
유창노→유재진 2020.10.13   56,080,000원 → 10,879,520원  (10년합산 + 기납부공제, 일치)
유태로→유재진 2022.09.13 1,000,000,000원 → 229,890,000원 (기타친족 1천만 공제, 일치)
```

불일치 5건:
- 3건(유해인·유지원·유태현의 월산리20-13 토지) — 신고액이 **연부연납 가산금 포함 실납부액**. 순 증여세는 엔진값이 정확.
- 1건(유태현 2017.05.25) — 당시 **미성년자**. 설정에서 생년월일을 입력하면 69,311,820원으로 정확히 일치합니다.
- 1건(유해인 2017.07.30, 차이 8만원) — 신고세액공제율 7%(2017년) 대신 5%가 적용된 기록.

## 구조

```

```
